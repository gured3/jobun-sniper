条文スナイパー　はじめにお読みください
==========================================

■ 中身（6つのファイルは必ず同じフォルダに置いてください）
  index.html ............ アプリ本体
  sw.js ................. オフラインでもすぐ起動するための部品
  manifest.webmanifest .. ホーム画面に追加したときの設定
  icon-192.png / icon-512.png / apple-touch-icon.png ... アイコン


■ GitHub Pages に置く（論PASSと同じ手順）
  1. GitHub 右上の「＋」→「New repository」→ 名前（例：jobun-sniper）→ Public → Create repository
  2. 「uploading an existing file」を押し、6つのファイルをまとめてドラッグ →「Commit changes」
  3. Settings → Pages → Branch を「main」「/(root)」にして Save
  4. 数分後、https://（ユーザー名）.github.io/jobun-sniper/ で開けるようになります
  ※ 公開されるのはアプリの部品だけです。成績や追加した問題は公開されません。


■ iPhone・iPad
  Safari で上のURLを開く → 共有ボタン →「ホーム画面に追加」
  以後はホーム画面のアイコンから起動。機内モードでも動きます。
  ※「Safariのタブ」と「ホーム画面のアイコン」は保存場所が別です。必ずアイコンから使ってください。

■ Windows
  上のURLを Edge で開く → 右上「…」→「アプリ」→「このサイトをアプリとしてインストール」
  → スタートメニューから起動。オフラインでも動きます。


■ クラウド同期（3台で同じ記録を使う）
  アプリの「同期・設定」→「クラウド同期（GitHub）」に入力します。
  ・論PASSで作った Private のデータ用リポジトリ（例：ronpass-data）とトークンを、そのまま使えます。
    データは別のファイル（jobun-sniper/data.json）に保存されるので、論PASSのカードとは混ざりません。
  ・まだ無い場合は、アプリ内の「はじめての設定のしかた」の手順で作ってください。
  ・各端末で1回ずつ「保存して同期」を押せば、以後は起動時・解答のあと・アプリを閉じるときに自動で同期します。
  ・右上の ☁ ボタンでいつでも同期できます。


■ アプリを新しい版に更新するとき
  GitHub の同じリポジトリで「Add file」→「Upload files」→ 新しいファイルを全部ドラッグ（同じ名前は上書き）
  → アプリをネット接続中に2回起動すると新しい版になります。成績は消えません。


■ 圧縮六法（ソース）を読み込む
  「同期・設定」→「圧縮六法（ソース）」→「ファイルを選ぶ」で、圧縮六法の .docx（複数可）を選び、
  法令を確認して「読み込む」。答え合わせの画面に、その条文の内容と「体系上の位置」が出ます。
  パソコンで1回読み込めば、クラウド同期で iPhone・iPad にも届きます。
  ※ 条文番号（例：九四、一四三、九五-一）が行の先頭にある形式に対応しています。
  ※ 教材を書き直したら、もう一度読み込むと上書きされます。

■ 主な操作
  ・出題：科目を選ぶ → 条をダイアル（指・Apple Pencilで上下になぞる／▲▼）で合わせ、項・号を押して「撃つ！」
  ・出題設定：種別、配置（自動／横／縦）、目次の表示、文字の大きさ、入力方式（ダイアル／テキスト）
  ・問題の文字は、問題枠の「A−」「A＋」でもすぐ変えられます
  ・キーボード：数字キーでダイアル入力、Backspaceで1桁戻す、Enterで解答・次へ
  ・入力枠（ダイアル・ボタン・テキスト欄）の大きさは、解答欄の「枠−」「枠＋」か出題設定の「入力枠」で4段階
・判定：85点以上＝合格（演出あり）、55〜84点＝惜しい（演出あり）、40〜54点＝射程内、40点未満＝大外れ（射程内と大外れは復習リストへ）
・同期・設定：圧縮六法の読み込み、略語表示（略語一覧の表記）、演出のオン・オフ、Apple Pencilの設定、バックアップ
