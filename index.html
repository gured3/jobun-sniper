      追加した問題

        圧縮六法（ソース）

        ご自分の圧縮六法（Word・.docx か .txt）を読み込むと、答え合わせの画面にその条文の内容が出て、目次も教材の「編・章・節・款」に合わせて細かくなります。1台で読み込めば、クラウド同期で他の端末にも届きます。

        ☁ クラウド同期（GitHub）

        Windows・iPhone・iPadで、成績・復習リスト・追加した問題・圧縮六法を共有します。データはご自分のGitHubの非公開リポジトリに保存されます。論PASSと同じデータ用リポジトリ・トークンを使えます（保存するファイルは別です）。

        このプレビュー画面ではGitHub同期は使えません。GitHub Pagesに置いた「条文スナイパー」で設定してください。

        はじめての設定のしかた
        1. GitHubで「New repository」→ 名前を ronpass-data などにし、Private を選び、「Add a README file」にチェックして作成（論PASSで作成済みなら、それを使えます）。
          ※アプリを置く公開リポジトリとは別にしてください。
        2. 右上のアイコン →「Settings」→ 左下「Developer settings」→「Personal access tokens」→「Fine-grained tokens」→「Generate new token」。
        3. 「Repository access」で Only select repositories → データ用リポジトリを選ぶ。「Permissions」の Contents を Read and write にして作成。
        4. 表示された github_pat_… をコピー（一度しか表示されません）。
        5. 各端末のこの画面で、リポジトリ名とトークンを入れて「保存して同期」。
        トークンはこの端末の中にだけ保存され、バックアップにも含まれません。期限が切れたら作り直して入れ直してください。
